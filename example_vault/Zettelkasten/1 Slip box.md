# The slip box

A Zettelkasten is a web of small notes, each one idea, found through
links rather than folders [@luhmann1981].

Try the Zettelkasten plugin's commands (Ctrl+P, "Zettelkasten:"):
- **New sequel note** / **New branch note** here (`1` → `2`, `1` → `1c`).
- **Show sequence**: these notes in Luhmann's order.
- Type `[[1a Atomic notes#` for its headings, `[[^^web` for blocks anywhere.
- **Show local links**, **Show orphan notes**, **Quick capture**.
