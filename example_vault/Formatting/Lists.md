# Lists

## Bullets

Start a line with `-`, `*` or `+`:

- Fruit
  - Apples
    - Cox
    - Braeburn
  - Pears
- Vegetables

**Enter** continues the list (Enter on an empty item ends it), **Tab** and
**Shift+Tab** nest and un-nest an item, **Ctrl+K** folds an item with
items under it.

## Numbers

1. Numbers are put right as you edit:
2. press Enter after this item, or Tab on it,
3. and the numbers after it follow.

1) A parenthesis works too.
2) Like this.

## Paragraphs in an item

- An item can have more than one paragraph.

  Indent the next one to the item's text and it stays in the item.
- The next item.

## Tasks

- [ ] **Ctrl+T** makes a line a task
- [x] **Ctrl+L** checks it, or unchecks it
- [ ] Tasks nest like any item
  - [ ] a step
  - [x] a done step

1. [ ] Numbered tasks
2. [x] work the same

## Task states

A character other than `x` between the brackets is a state of its own:

- [/] in progress
- [>] forwarded
- [-] cancelled
- [!] important
- [?] a question
- [b] any letter you like

The [[Tasks]] plugin adds due dates, priorities and queries over them.
