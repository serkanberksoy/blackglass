# Emoji shortcodes

With the **Emoji Shortcodes** plugin, type `:` and a few letters: `:jo`,
`:thumbs`, `:tada`. Pick one with ↑/↓ and Enter: the emoji goes in. Those
you use come first next time.

Shortcodes written out show as their emoji where the cursor isn't:
:sparkles: :rocket: :coffee: :+1:

Highlights come in colors too: ==🔴urgent==, ==🟠soon==, ==🟡someday==,
==🟢done==, ==🔵info==, ==🟣idea==. Type `==` for a color, or select
text and run "Highlight in blue".

Settings → Emoji Shortcodes: keep the shortcode instead of the emoji, no
suggestions, the history.
