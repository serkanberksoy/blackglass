# Task Archiver

The **Task Archiver** plugin moves done tasks out of the way. Try its
commands from the palette (Ctrl+P, "Task Archiver: …"):

- *Archive tasks in this file*: the done tasks below go under an
  "Archived" heading at the end, with the date and the headings they were
  under.
- *Archive tasks including nested tasks in this file*: done subtasks of
  open tasks too.
- *Toggle task done and archive it*: put the cursor on a task.
- *Sort tasks in list under cursor*: items, then open tasks, then done ones.
- *Archive heading under cursor*: try it on "Old project".
- *Delete tasks in this file*: the done tasks are gone (undo brings them
  back).

Settings → Task Archiver: archive to another note or the daily note, a
date tree of list items (`[[{{date:YYYY-[W]WW}}]] > [[{{date}}]]`), rules
for some tasks (by status, note, text).
