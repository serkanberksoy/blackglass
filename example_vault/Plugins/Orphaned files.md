# Orphaned files

**Orphaned files** finds what's loose in the vault. Press **Ctrl+P** and
run **Find orphaned files and broken links**: a report is written to
`Orphaned files and broken links.md` at the top of the vault and opened.
It lists:

- **Orphaned files:** notes, images and other files no note links to.
- **Broken links:** links to notes or files that don't exist, with the
  note each is in. Click one to make the note.
- **Empty files:** notes with nothing in them, or nothing but
  properties.
- **Empty folders:** folders with no files in them.

Run it again whenever you like: the report is brought up to date (Ctrl+Z
undoes that). There's a command for each search on its own too: **Find
orphaned files**, **Find broken links**, **Find empty files**, **Find
empty folders**.

In Settings (**Alt+,**) → Orphaned files you can leave folders out
(`Templates, Journal`), notes with some tags, and file types
(`pdf, png`); say that files linking to a hub note aren't orphans; sort
the orphans by size; and name the report.

Try it here: this vault's journal and templates have no notes linking to
them, so they show up as orphans unless you leave those folders out.
