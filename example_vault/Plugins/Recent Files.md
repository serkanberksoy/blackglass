# Recent Files

A **Recent** tab in the sidebar: the last 25 notes you visited, newest
first.

It's not on in this vault: **Alt+,** → Plugins → Recent Files, Enter
installs it, Space turns it on. Then open a few notes and look at the
Recent tab.

- Enter opens a note, **l** puts a link to it at the cursor, Delete takes
  it off the list; "Recent Files: Clear list" empties it.
- Settings: how many notes, notes changed (not only visited), paths and
  tags to leave out, titles instead of names.

The list is kept per vault, in `.blackglass/plugins/recent-files/`.
