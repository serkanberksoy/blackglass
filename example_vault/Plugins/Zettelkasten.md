# Zettelkasten

Small notes, each one idea, linked to each other. The notes in
`Zettelkasten/` are a small slip box: start at [[1 Slip box]].

## Linking

- Type `[[1a Atomic notes#` for that note's headings, `[[1a Atomic notes#^`
  for its blocks (one without an ID gets one when chosen), `[[##` for
  headings anywhere, `[[^^web` for blocks anywhere.
- "Copy link to this note / heading / block".
- "New unique note linked from here": a note named by an ID, linked at the
  cursor (the selection becomes the link's text).

## Structure

- **Folgezettel**: "New sequel note" (`1` → `2`) and "New branch note"
  (`1` → `1a`); "Show sequence" lists them in order in a Sequence tab; "Go
  to next / previous / parent in sequence".
- **Breadcrumbs**: `up`, `down`, `next`, `prev` properties ("Go up" …), as
  in [[1 Slip box]].
- Titles instead of IDs (a setting) wherever notes are named.

## Refactoring

"Extract selection to another note", "Extract this heading", "Split note at
headings", "Merge this note into another" (every link follows).

## Finding

"Show orphan notes", "Show dead-end notes", "Show unresolved links", "Show
local links" (a Links tab: links out and in as a tree); link counts beside
links (on in this vault); "Quick capture" to an `Inbox` note.
