# Bookmarks

Keep the notes, headings, folders and searches you come back to in a
**Bookmarks** tab in the sidebar.

- "Bookmarks: Bookmark this note" (again: takes it off).
- "Bookmark this heading": the heading above the cursor; it opens there.
- "Bookmark this folder": the folder chosen in the file explorer.
- "Bookmark the search": the sidebar's search, run again when opened.

In the Bookmarks tab: Enter opens one, **r** renames it, Delete removes it.
A bookmarked note that's renamed or moved keeps its bookmark.

This vault has a few already: [[Welcome]], [[Dune]], the `Plugins` folder
and the search `tag:#reading`. They're kept in
`.blackglass/plugins/bookmarks/bookmarks.json`, the original's format.
