# Properties

The lines between `---` at the top are this note's **properties**. They show
typed: a checkbox, a date, a list as chips, tags.

- **Alt+;** edits them in a window: Enter edits a value (or switches a
  checkbox), **a** adds one, **r** renames, Delete removes.
- Typing in the frontmatter suggests property names, and the values a
  property has in other notes.
- "Show properties" (Ctrl+P) lists every property in the vault with how
  many notes have it; Enter searches for them. "Rename property" renames
  one in every note.
- `aliases` are other names: **Ctrl+O** finds this note as `Frontmatter`
  too, and `[[` suggests it.

Properties are what [[Dataview]], [[Bases]] and the vault search (`[rating:4]`)
read.
