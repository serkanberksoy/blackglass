# Notes and files

- **Ctrl+N** makes a note in the folder chosen in the file explorer
  (`Untitled`, `Untitled 1` …); in its window **Tab** picks a template.
  A name with `/` makes folders.
- **Note IDs**: Settings → Notes gives every new note a unique ID from the
  time (`202610071230`): in its name, as its name or in its properties.
- **F2** renames a note (or the file or folder chosen in the explorer);
  every link to it is updated. "Move file" moves it the same way.
- "Delete note" moves it to the vault's `.trash/` folder (asked first).
- **Ctrl+X** with text selected moves it to a new note and links to it.
- **Ctrl+Alt+S** saves the note under another name.
- "PDF to note" writes a PDF's text into a note beside it, to read, search
  and link.
- "Open random note" (Ctrl+P), for rediscovering.
- A rename, move or delete (and what commands do to other notes) is
  undone with Ctrl+Z when the open note has nothing of its own to undo,
  or with "Undo last change to other notes".

Images and other files sit beside the notes, like `assets/sunset.png` shown
in [[Sunset]]; a click opens one in the system viewer.
