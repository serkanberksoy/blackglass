# Links and embeds

## Links

- `[[Dune]]` links to a note anywhere in the vault; `[[Dune#Spice]]` to a
  heading, `[[Dune#^parts]]` to a block, `[[Dune|the book]]` shows other
  text. A link to a note that doesn't exist yet is dimmed: [[Not written yet]].
- Type `[[`: the notes you visited lately, then a search as you type; Enter
  or Tab puts the link in.
- **Ctrl+Enter** (or a click) follows a link in a tab; a missing note is
  offered to be made. **Alt+P** previews the linked note in a popup.
- Web links open in the browser: https://example.org

## Around this note

- **Alt+L** shows the notes linking here (backlinks), notes naming it
  without a link (**l** makes the link), and its own links out.
- **Alt+O** lists its headings to jump to.

## Embeds

`![[…]]` shows another note, a part of it, an image or a base in place.

A block of another note: in [[Dune]], `^parts` names its table:

![[Dune#^parts]]

A heading's section:

![[Dune#Dune]]

An image (a click opens it in the system viewer; terminals that can draw
images show it):

![[sunset.png]]

A view of a base:

![[Library.base#Cards]]

A search run in place (see [[Search and tags]]):

```query
spice
```
