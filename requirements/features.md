# blackglass features

What blackglass adds around mdedit. The editor's own features (live
preview, tables, callouts, search in a note, undo …) are mdedit's and are
tracked in `../mdedit/requirements/obsidian_features.md`. mdedit's rows with
the milestone **Wrapper** belong here; their mdedit ID is in the Notes.

**Now:** ✅ done · 🟡 partial (Notes say what's missing) · ⬜ not started.
**Test:** the automated test that proves the row, as `file::test_name`.
`tests/project.rs` checks that every ✅ / 🟡 row names a test that exists.
